# 🐦 Flappy Bird – Python Pygame

---

## 🌟 Overview
**Flappy Bird** is a classic arcade game recreated using **Python** and **Pygame**.  
The goal is simple: 🐦 navigate the bird through the pipes 🌿 and score as many points as possible without colliding.

---

## 🎮 Features
- 🕹 **Simple Gameplay:** Tap/spacebar to make the bird flap  
- 📈 **Score Tracking:** Earn points as the bird passes through pipes  
- ⚡ **Responsive Controls:** Smooth and fast input handling  
- 🎨 **Retro Graphics:** Classic 2D style visuals and fun sound effects  

---

## 🛠 Technologies Used
- **Programming Language:** Python 3.x 🐍  
- **Game Library:** Pygame 🎮  
- **Graphics & Sound:** Custom sprites & sound effects 🎵
