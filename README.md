Flappy Bird Game

A classic Flappy Bird game implemented in Python using the Pygame library.

Gameplay

- Control the bird's movement by pressing the space bar to flap its wings.
- Avoid hitting the pipes and the ground to survive.
- Score points by passing through the pipes.

Features

- Simple and intuitive gameplay
- Smooth animations and sound effects
- Score tracking and display

Requirements

- Python 3.x
- Pygame library

Code Structure

The code is organized into several modules:

- bird.py: Bird class implementation
- pipe.py: Pipe class implementation
- game.py: Game logic and main loop implementation
